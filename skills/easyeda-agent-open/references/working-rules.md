# 嘉立创 EDA Open 工作规则

目标：准确落图、快速续接，工程师终审。用户任务决定范围，保留已确认设计。BLOCK 指不能把已知错误或未知当作正确结果交付；WARN 为图面改进提醒。进入绘图或压缩恢复时读取本文件，连续小步复用；PCB、制造、选型、同步和离线格式只读 [条件规则](conditional-rules.md) 的相关段落。

## 绘图依据

- 上游流程：资料解读确认 → 工程师给目标 → 查料及符号/封装核对 → 确认具体执行文件 → 落图。复用该版该范围的确认，不增加插件审批。执行文件至少包含目标及范围、器件/符号/封装/引脚证据、位号·脚号→网络或明确 NC、功能参数、未决项和验收范围；已有 BOM/网表可引用，坐标与线形在绘图时决定。
- 资料事实、工程师决定、候选与未知分开。纯排版保留器件和逐脚连接；设计或范围变化才确认改变的设计决定，坐标微调及绘图故障无需重新确认。无参考图时根据已确认的功能与真实连接推导排版，不猜测功能或重新设计电路。封装缺证据不能称 PCB 可用。（S01、S02、L01–L04）

## 执行节奏与证据

- 写前确认窗口、工程、文档和对象，多窗口固定 windowId；同批不重复查询未变身份。器件用 uniqueId、库/封装 ID、位号和脚号识别，截图与位号不能单独证明身份。null、缺失、失败与明确 NC 分开。（A01–A03、C01）
- 先结合当前整体图面和真实连接确定相对位置、朝向、主路径及文字空位，再成组放置、接线；整页或本次局部范围完成后统一看完整结果、核对逐脚网络并做必要 DRC。不要在移件、拆线、重接的中间状态逐步跑 DRC、全页检查或反复截图；临时断线不作为撤回依据。（A05、S08）
- 当前原理图排版接线任务：最终 DRC error/fatal 作为错误，warn/info 结束简报，不因数量增加调查、撤回或扩大修复。逐脚数据已证实的错接/漏接仍须修正，未知不能称通过。此约定不代替 PCB 制造验收。
- 读取合并，写入优先 batch 或一个原生脚本；批次非事务，保留逐步回执。未知 API 按具体方法查签名、单位和返回值，已确认调用复用。外层 ok 不掩盖内层错误；超时、部分成功、ID 失效后先局部回读，只续做未落地部分。新指令废止未执行旧步骤。（A04、A09、A11、C02、C06）
- 局部返工复用基线及对象/关联网络，仅回读受影响部分和范围外不变量；身份变化、基线失效、影响不明或整页交付缺新鲜证据才重读整页。模型收到局部投影不等于底层增量读取。网表结论注明来源和页面范围，覆盖不足不称全工程通过。（A06、C04）
- 本次全部修改及最终必要检查结束后才主动保存，并确认 saved:true；中间批次与临时返工不主动保存，用户另有要求除外。宿主自动保存另计；仅需证明持久化或状态疑似陈旧时重载。可逆小改不默认导出备份，高影响覆盖/批删/整板同步按具体风险处理。（A07、A08）

## 通用排版与接线

总原则：模块内紧、模块间松，局部关系优先短线直连，跨模块关系优先真实网络名；让工程师快速读懂。以下图面取舍为 WARN，真实身份与电气错误为 BLOCK。

1. **关系先于坐标。** 先识别主路径、串联链、分支、汇合和反馈，再选布局；关联器件围绕共同节点靠近，模块靠自然留白分隔。不套固定九宫格、核心器件居中或电源在左，不用大段空白和长线弥补松散摆放。（S06）
2. **串联链同轴，支路就近展开。** 直接配合的串联器件尽量沿同一水平/竖直路径；支路靠所属节点摆放。旋转、错位或阶梯摆放用来减少绕线；对齐引脚和连接节点，不强求器件中心对齐。上下方向按真实关系和已有规范决定。
3. **局部关系保持可见。** 串联、反馈、上下拉、去耦、滤波、驱动等局部关系优先直接导线；反馈的采样节点、反馈器件和返回端应能顺着线读懂。不要为了线短而拆成多个同名标签；不按具体芯片或案例套固定拓扑。
4. **跨区使用真实网络名。** 跨功能模块、大片空白或需绕开无关器件时使用短导线加网名，不设固定距离阈值、不横穿大片页面。EasyEDA Pro 网名是导线 Name 属性，必须落在真实导线上；跨页按当前作用域核对，作用域未知不能凭同名认定连接。
5. **需要画导线时先向引脚外侧引出，再转弯。** 依据真实连接端及引脚朝向，先形成非零短引线再折弯，留出符号边框、引脚号和文字空间。不得向器件内部折返或沿边框压线。平台原生网络名、电源或地等方式如已形成真实连接，不强制另加短线。同侧引脚符号允许短折线，不强行套对向引脚画法；不为排版换器件/库绑定。（S03、S05）
6. **线形短而清楚。** 通常水平/竖直，少折返、少交叉，不穿器件主体或重要文字。不设统一最大线长，不因稍长拆开必要直连，也不用超长线补救器件距离。线宽、网格和短桩取当前宿主/任务依据，不从像素猜精确落点。（S05、S07、S13）
7. **摆放时给文字留位。** 位号、必要参数和网名一起安排，网名在实际所属导线附近或上方，避开引脚号及其他导线。同类方向尽量一致；保留既有命名，不为统一画风大面积改名。完成本次范围后统一视觉检查，局部问题局部修。（S08、S10）
8. **同网合理共用。** 同一局部先形成清楚分支再标名，相距较远或不同模块可用同名网；不规定每脚一标签或标签数量上限。内部已由直连清楚表达的网名可隐藏显示，真实网络属性保留；跨区端点须有可读网名或真实电源/地符号，不能隐藏连接依据。相邻接口可共用分支，但避免因此形成复杂交叉。
9. **连接以真实网络为准。** 引脚、导线、网名及电源/地须真实相连，禁止零长度占位线和仅文字贴近。编辑器自动生成引线可接受，以回读为准。T 分支应相连，非连接跨线保持不同网络；不得因名称相似合并。故意不用的引脚保留明确 NC，不为消警告改变意义。（S03、S04、S09）
10. **视觉参与规划和最终验收。** 看主路径、关联器件距离、引脚出线、线形及文字遮挡；宏观表达用图面，身份和电气用结构化数据。必要时放大风险局部，不能用 DRC 无错代替图面合格，也不追求全量文字框清零。

## 提速与防遗漏

- **自动覆盖入口：** 将完整修改单元与器件范围提交到 `edit`，程序核对确定性事实并记录 pass/fail/unknown；纯文字显示操作不重复编译网表。局部返工用后台观察定位对象；事件覆盖未可靠验证时，缓存不作为新鲜位置依据，按对象 ID 定向刷新。原生事件只作提示；普通完整单元执行前后局部回读，暂停续接/finish 强制对照当前局部实况，不一致返回局部事实供修正剩余计划，不重放成功步骤。文字测量提供包括自身位号/参数与所属器件交叠的 WARN 候选；包围框可能含属性，须用当前局部图面排除误报。可见性为 null 不等于隐藏；可见性未明确且原生 BBox 为零面积的属性没有碰撞区域，可见文字缺测保持 unknown。完整范围图面审阅仍由 AI 承担。任务要求 DRC 时显式声明，不在每个中间步骤运行。调用及续接方法以 SKILL.md 为唯一说明。
- 模型决定功能关系、相对位置和朝向；重复坐标运算优先用现有脚本/原生脚本从真实引脚计算，统一网格及向外短引线，避免逐点手算。旋转/镜像的约定须已确认；不确定时在移件批次末仅回读受影响引脚几何后接线。这是执行方法，不宣称已有完整自动布局器。
- 合理的局部整体平移，大幅重排区域才重建接线；网名显示与文字空位随同批方案处理。复用已确认窗口、API 参数和读取结果，不重复查整套目录或输出全量对象。
- 复用现场已成功的查看路径。当前宿主 view.region 曾比例异常；局部可 select → fit_selection → sch_SelectControl.clearSelected() 再截图。空数组选择不保证清除；若图面陈旧，改用对象范围导出，不重复相同失败。结束恢复方便用户查看的视图。
- **开工提醒：** 目标与基线 → 主路径/节点关系 → 朝向、引脚出口和文字空间；**收尾提醒：** 图面 → 逐脚/身份 → 最终 DRC → 保存回执。作为决策提示复用现有证据，不增加审批、逐条工具调用或第二轮固定检查。压缩恢复时重读本文件并沿用既有任务进度，仅续做剩余范围。

不启用固定阶段、双轮自检、逐阶段签字、默认虚线框/模块标题、固定九宫格/间距、默认圆角及案例器件清单。P01 单件 PCB 补齐快捷路径仍待定。（A10、S11、S12、P12、R09、L06）

平台参考：[网络名](https://prodocs.easyeda.com/en/schematic/place-net-label/)、[导线](https://prodocs.easyeda.com/en/schematic/place-wire/)；规则文字和代码化检查分别说明，写入规则不等于自动强制执行或真实 EDA 验收。


## 任务与工程状态的持久化（open.9）

复用 daemon 的唯一工程观察与回执，不另建 Markdown 版状态机。调用者的任务目标/范围/剩余事项是意图；自动回执是执行证据。入口和恢复方法见 Skill 的“任务连续性”。按影响范围原生回读，恢复后的缓存不提供新鲜坐标、逐脚网络或续跑授权。任务说明不能证明规则已执行；规则仍由实际动作链执行。
