# 嘉立创 EDA Open 工作规则

目标：准确落图、快速续接，工程师终审。用户任务决定范围，保留已确认设计。BLOCK 指不能把已知错误或未知当作正确结果交付；WARN 为图面改进提醒。进入绘图或压缩恢复时读取本文件，连续小步复用；PCB、制造、选型、同步和离线格式只读 [条件规则](conditional-rules.md) 的相关段落。

## 规则索引与按动作入口

本文件是当前 Open 原理图规则的唯一正文；下列 ID 只索引下文既有条款，不增加自动门禁或另一份规则。A 为观察和执行，S 为原理图表达，C 为连接和范围，L 为资料与身份。回执沿用稳定项 identity、pin_nets、valid_wires、pin_exit、text_overlap 与 visual_review，并以 scope/readScope 表示观察范围；其中 visual_review 是待看图的 WARN 项，和 runtime 的视觉记录不是同一证据。unknown 不能写成 pass。

- 放置、移动、旋转：按 A01–A06、S01–S02、S06，读取目标对象的 identity、bbox、pins 并回读实例/几何；关系、朝向与模块留白由 AI 看当前图面决定。
- 接线、局部返工：按 A04、A06、A09、C01–C06、S03–S05、S09，读取相关 pin/net、wire 和必要 bbox；pin_nets、valid_wires、pin_exit 与 scope 可核，原生已连的网名/电源/地不强制补 stub。
- 网名与文字显示：按 S04、S07–S08、S10，创建前决定必要可见网名，使用真实 wire/attribute ID、显式显示意图和必要局部文字；仅官方 display 属性可按 display-only 处理，纯显示不重读 pin 网络。必要可见名称、文字空位和可读性由 AI 判断，不把生成后隐藏作为默认创建流程。
- 收尾、保存、恢复：按 A07–A08、S08、S10、C04，查看本次范围图面、逐脚/身份和任务要求的 DRC；WARN 不在中间硬拦，明显图面问题先局部修。完成必要检查后保存并核实 saved:true，仅任务要求持久化证明或状态可疑时重开。

没有单独入口的工作不因本索引新增读取；按下文相应条款执行。

## 绘图依据

- 上游流程：资料解读确认 → 工程师给目标 → 查料及符号/封装核对 → 确认具体执行文件 → 落图。复用该版该范围的确认，不增加插件审批。执行文件至少包含目标及范围、器件/符号/封装/引脚证据、位号·脚号→网络或明确 NC、功能参数、未决项和验收范围；已有 BOM/网表可引用，坐标与线形在绘图时决定。
- 资料事实、工程师决定、候选与未知分开。纯排版保留器件和逐脚连接；设计或范围变化才确认改变的设计决定，坐标微调及绘图故障无需重新确认。无参考图时根据已确认的功能与真实连接推导排版，不猜测功能或重新设计电路。封装缺证据不能称 PCB 可用。（S01、S02、L01–L04）

## 执行节奏与证据

- **只读取当前任务需要的信息。** 先确定要画/改的对象和所需字段，复用仍有效的证据；摆件取位置、朝向、引脚和必要边界，接线取真实引脚/网络，排文字再补相关可见属性。未知范围先用必要的对象清单或图面定位，再定向读取；不默认遍历全页隐藏属性、3D 模型或无关图框字段。无关信息缺失不阻塞绘图，也不为补齐库存扩大调试；必要身份、连接或受影响对象不明时，只补所需证据或暂停依赖该缺项的操作。整页重画须覆盖全页器件/逐脚目标，但不等于读取全部字段；全页清除等破坏性操作仍须满足原有保护检查，不能借“少读”绕过。
- 写前确认窗口、工程、文档和对象，多窗口固定 windowId；同批不重复查询未变身份。器件用 uniqueId、库/封装 ID、位号和脚号识别，截图与位号不能单独证明身份。null、缺失、失败与明确 NC 分开。（A01–A03、C01）
- 先结合当前整体图面和真实连接确定相对位置、朝向、主路径及文字空位，再成组放置、接线；整页或本次局部范围完成后统一看完整结果、核对逐脚网络并做必要 DRC。不要在移件、拆线、重接的中间状态逐步跑 DRC、全页检查或反复截图；临时断线不作为撤回依据。（A05、S08）
- 当前原理图排版接线任务：最终 DRC error/fatal 作为错误，warn/info 结束简报，不因数量增加调查、撤回或扩大修复。逐脚数据已证实的错接/漏接仍须修正，未知不能称通过。此约定不代替 PCB 制造验收。
- 读取合并，写入优先 batch 或一个原生脚本；批次非事务，保留逐步回执。未知 API 按具体方法查签名、单位和返回值，已确认调用复用。外层 ok 不掩盖内层错误；超时、部分成功、ID 失效后先局部回读，只续做未落地部分。新指令废止未执行旧步骤。（A04、A09、A11、C02、C06）
- 局部返工复用基线及对象/关联网络，仅回读受影响部分和范围外不变量；身份变化、基线失效、影响不明或整页交付缺新鲜证据才重读整页。模型收到局部投影不等于底层增量读取。网表结论注明来源和页面范围，覆盖不足不称全工程通过。（A06、C04）
- 本次全部修改及最终必要检查结束后才主动保存，并确认 saved:true；中间批次与临时返工不主动保存，用户另有要求除外。宿主自动保存另计；仅需证明持久化或状态疑似陈旧时重载。可逆小改不默认导出备份，高影响覆盖/批删/整板同步按具体风险处理。（A07、A08）

## 通用排版与接线

总原则：模块内紧、模块间松，局部关系优先短线直连，跨模块关系优先真实网络名；让工程师快速读懂。以下图面取舍为 WARN，真实身份与电气错误为 BLOCK。

1. **关系先于坐标。** 先识别主路径、串联链、分支、汇合和反馈，再选布局；关联器件围绕共同节点靠近，模块靠自然留白分隔。不套固定九宫格、核心器件居中或电源在左，不用大段空白和长线弥补松散摆放。（S06）
2. **串联链同轴，支路就近展开。** 直接配合的串联器件尽量沿同一水平/竖直路径；支路靠所属节点摆放。旋转、错位或阶梯摆放用来减少绕线；对齐引脚和连接节点，不强求器件中心对齐。同类重复电路尽量保持一致的方向与阅读次序，对称关系用对应摆放表达；不为几何对称改变真实连接。上下方向按真实关系和已有规范决定。
3. **局部关系保持可见。** 串联、反馈、上下拉、去耦、滤波、驱动等局部关系优先直接导线；反馈的采样节点、反馈器件和返回端应能顺着线读懂。已经直连且没有连接其他区域用途的局部网络，默认不添加可见网络名，不给每段内部导线命名展示。不要为了线短而拆成多个同名标签；不按具体芯片或案例套固定拓扑。
4. **跨区默认用短导线加网络名。** 分开摆放但需要电气相连的电路、跨功能模块、大片空白或需绕开无关器件的连接，默认用短导线加真实网络名，不使用六边形网络端口/标签；不设固定距离阈值、不横穿大片页面。EasyEDA Pro 网名是导线 Name 属性，必须落在真实导线上，不能用普通文本代替。电源/地仍可使用正常符号。用户明确指定端口，或经核实的跨页/层级连接语义必须使用端口时按实际要求处理；跨页作用域未知不能凭同名认定连接。
5. **需要画导线时先向引脚外侧引出，再转弯。** 依据真实连接端及引脚朝向，先形成非零短引线再折弯，留出符号边框、引脚号和文字空间。不得向器件内部折返或沿边框压线。平台原生网络名、电源或地等方式如已形成真实连接，不强制另加短线。同侧引脚符号允许短折线，不强行套对向引脚画法；不为排版换器件/库绑定。（S03、S05）
6. **线形短而清楚。** 通常水平/竖直，少折返、少交叉，不穿器件主体或重要文字。不设统一最大线长，不因稍长拆开必要直连，也不用超长线补救器件距离。线宽、网格和短桩取当前宿主/任务依据，不从像素猜精确落点。（S05、S07、S13）
7. **器件文字贴近器件，网名贴紧导线。** 位号与参数作为一组，放在所属器件近旁的空闲位置，只保留清晰可读的小间隙，优先避免与器件主体、边框、引脚、其他文字或导线重叠。少量且不影响识别的重叠可接受；遮挡关键信息、连接点或使所属关系不清时修正，不为零重叠反复返工。不要为避让把文字远远推开；先换到器件相邻的合适一侧或调整局部留位，不套固定大偏移。导线网络名的文字基线/放置锚点直接贴在实际所属导线上，字形从导线上方清晰展开，不悬空留一段距离，优先避免导线穿过字形。网名在本段导线上选择空位，避开引脚号、器件和分支交点；真实 Name 属性及网络不变。同类方向尽量一致；保留既有命名。完成本次范围后看实际图面确认贴近且可读，局部问题局部修。（S08、S10）
8. **同网合理共用，创建前确定可见网名。** 同一局部先形成清楚的导线分支，仅在需要表达外部连接时标名；相距较远或不同模块可用同名网，不规定每脚一标签或标签数量上限。已直连且无其他区域连接用途的内部网络，新建方案不额外生成可见名称，不默认先给所有导线标名再隐藏；电气网络身份与可见表达分开处理，创建方式仍须证明真实逐脚归网正确。是否有外部用途按真实网络成员和已确认设计判断，不能只看局部截图。跨区端点须保留可读网名或真实电源/地符号，不能隐藏连接依据。已有内部名称的显示调整须保留真实 Name 属性和电气关系；当前隐藏保存重开尚未通过，不反复尝试同一机制，也不以清空Name或删线代替。相邻接口可共用分支，但避免因此形成复杂交叉。
9. **连接以真实网络为准。** 内部直连网可在独立方案中显式按完整引脚成员比较，原生自动编号允许不同；明确命名的电源、跨模块等网络仍核对名称。比较方式由drawing-files契约及同一原生网表检查执行，不能把隐藏文字当成名称不重要的依据。 引脚、导线、网名及电源/地须真实相连，禁止零长度占位线和仅文字贴近。编辑器自动生成引线可接受，以回读为准。T 分支应相连，非连接跨线保持不同网络；不得因名称相似合并。故意不用的引脚保留明确 NC，不为消警告改变意义。（S03、S04、S09）
10. **视觉参与规划和最终验收。** 看主路径、关联器件距离、引脚出线、线形、器件文字是否贴近且无重叠、网名是否贴紧所属导线、多余内部网名及是否遵循短导线加网名的默认画法；宏观表达用图面，身份和电气用结构化数据。必要时放大风险局部，不能用 DRC 无错代替图面合格，也不追求全量文字框清零。

## 提速与防遗漏

- **原生档案、目标方案与实际观察分开。** 需要落档时保存本次所需范围的真实 JSON，Markdown 为派生阅览；已取得的必要身份、属性及逐脚网络不能丢为只有数量/网名的摘要，落档不构成额外全量读取的理由。整页重画对照独立目标的器件/引脚全集，防止少画器件后对当前残图自检仍通过。局部 patch 保留源引用，不把未读取的对象删除或刷新为新鲜。具体入口、资料转换与范围边界只维护在 [资料及绘图文件](drawing-files.md)。

- **自动覆盖入口：** 将完整修改单元与器件范围提交到 `edit`，程序核对确定性事实并记录 pass/fail/unknown；纯文字显示操作不重复编译网表。要求声明本身仍不是覆盖；只有 drawing-files.md 列出的 R2 固定映射才可由当前阶段回执给出结果。局部 scope 必须同时匹配计划目标、实际 readback 身份和本批规则范围；缺失、partial 或不一致保持 unknown。design 修改的逐脚期望从独立 semantic target 派生，不能由调用方覆盖。局部返工用后台观察定位对象；事件覆盖未可靠验证时，缓存不作为新鲜位置依据，按对象 ID 定向刷新。原生事件只作提示；普通完整单元执行前后局部回读，暂停续接/finish 强制对照当前局部实况，不一致返回局部事实供修正剩余计划，不重放成功步骤。文字测量提供包括自身位号/参数与所属器件交叠的 WARN 候选；包围框可能含属性，须用当前局部图面排除误报。可见性为 null 不等于隐藏；可见性未明确且原生 BBox 为零面积的属性没有碰撞区域，可见文字缺测保持 unknown。完整范围图面审阅仍由 AI 承担。任务要求 DRC 时仅 final 显式声明后运行一次，error/fatal/unknown 不得降级，warn/info 不阻塞。调用及续接方法以 SKILL.md 为唯一说明。
- 模型决定功能关系、相对位置和朝向；重复坐标运算优先用现有脚本/原生脚本从真实引脚计算，统一网格及向外短引线，避免逐点手算。旋转/镜像的约定须已确认；不确定时在移件批次末仅回读受影响引脚几何后接线。这是执行方法，不宣称已有完整自动布局器。
- 合理的局部整体平移，大幅重排区域才重建接线；网名显示与文字空位随同批方案处理。复用已确认窗口、API 参数和读取结果，不重复查整套目录或输出全量对象。
- 复用现场已成功的查看路径。当前宿主 view.region 曾比例异常；局部可 select → fit_selection → sch_SelectControl.clearSelected() 再截图。空数组选择不保证清除；若图面陈旧，改用对象范围导出，不重复相同失败。结束恢复方便用户查看的视图。
- **开工提醒：** 目标与基线 → 主路径/节点关系 → 朝向、引脚出口和文字空间；**收尾提醒：** 图面 → 逐脚/身份 → 最终 DRC → 保存回执。作为决策提示复用现有证据，不增加审批、逐条工具调用或第二轮固定检查。压缩恢复时重读本文件并沿用既有任务进度，仅续做剩余范围。

不启用固定阶段、双轮自检、逐阶段签字、默认虚线框/模块标题、固定九宫格/间距、默认圆角及案例器件清单。P01 单件 PCB 补齐快捷路径仍待定。（A10、S11、S12、P12、R09、L06）

平台参考：[网络名](https://prodocs.easyeda.com/en/schematic/place-net-label/)、[导线](https://prodocs.easyeda.com/en/schematic/place-wire/)；规则文字和代码化检查分别说明，写入规则不等于自动强制执行或真实 EDA 验收。


## 任务与工程状态的持久化（open.9）

复用 daemon 的唯一工程观察与回执，不另建 Markdown 版状态机。调用者的任务目标/范围/剩余事项是意图；自动回执是执行证据。入口和恢复方法见 Skill 的“任务连续性”。按影响范围原生回读，恢复后的缓存不提供新鲜坐标、逐脚网络或续跑授权。任务说明不能证明规则已执行；规则仍由实际动作链执行。


## 局部显示修改与电气观察（S2）

纯显示修改（例如只移动位号）使用现有属性修改入口及局部显示回读，不重复编译网表。回读明确未请求网络、没有提供引脚或网络状态，且已观察的器件位置、朝向、身份和库绑定不变时，后台保留已有逐脚信息及其原有失效标记；原本失效或未知的电气信息不能因此变为新鲜。实际位置/朝向/身份变化，或读取明确提供未知网络时，仍使相关电气观察待回读。未涉及对象保持已有观察，不能把缓存视为已覆盖外部人工修改；必要电气验收仍须真实读取。显示修改使旧图面证据失效，最终审阅绑定本次范围和当前观察版本，不拿旧截图签新结果。


## 检查证据随修改失效（S2）

Open阶段回执与业务工作流使用相同判断：完成的官方纯显示修改必须有实际属性回读、所属器件匹配、目标身份正确和局部identity通过，才能保留前序身份/逐脚网络/导线合法性/出线/网络范围检查。这些保留项标为post_stage历史阶段证据，不伪装成新电气读取，也不替代整页最终目标核对。位号坐标、大小或显示改变后，旧文字碰撞和图面审阅不能继续签收。

连接或器件修改、原生失败/partial、无法证明为纯显示的步骤，使前序after_edit证据待复核；不能只凭两次primitiveIds不相交就认定电气互不影响，同一网络可能跨模块。当前采用保守失效，尚无完整跨模块依赖图。来源和计划改变沿用哈希绑定拒绝旧回执；外部人工修改仍依赖范围实读，缓存不是新鲜证据。失败后先回读已落地/缺项，不重放成功步骤。


性能执行约定：固定完整操作单元、摘要返回、必要读取与计时边界见drawing-files.md“日常操作的耗时边界”。局部state默认12条回执，省略量明确标注；完整历史显式读取，原始事实/unknown和检查门禁不省略。
