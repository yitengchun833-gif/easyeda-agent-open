# 原理图通用排版规则

版本：SCH-LAYOUT-2026-09-29.1。依据：用户本轮明确要求“把这个作为排版规则”；适用于任何原理图的新建、整理和重排，跨任务、接续和模型切换长期生效。

本页是原理图排版及操作保护规则的唯一维护处。跨来源整合、授权与当前任务规则确认遵循[规则管理](../../evidence-to-delivery/references/rule-management.md)。规则采用不代表授予新的工程写入权限，也不代表执行器已实现所有检查。

## 规则性质与生效

在不改变电气设计的前提下，图面应清楚表达：哪些器件共同完成一个功能，信号或电源从哪里来、经过什么、最终到哪里。判断顺序为：**功能关系 → 电气连接关系 → 阅读顺序 → 几何整洁度**。电气完整性为不可破坏的前提；美观、对齐、缩短导线不能覆盖实际连接关系。

不预设具体电路、拓扑数量、固定区域、坐标、网格尺寸或页划分。执行器读取当前设计，自行识别有依据的结构；证据不足的功能、方向、关系保留未知，不按公共网络或外观猜解。只暂停依赖该缺口的调整。

内部通用规范与外部用户/资料要求整合成当前任务的完整执行清单：每条保留稳定ID、来源版本、适用对象、具体要求、检查方法和冲突。用户当前明确要求优先于内部默认；与电气事实或工具能力矛盾时明示影响，不静默选边。新规则/依据/目标变化后，展示完整新版任务清单并取得对应确认；同版同范围已有有效确认可复用。用户本轮已确认本页通用规则，不能把此记录冒充其他工程的任务规则确认。

功能分组只作为内部分析数据；除非当前任务明确要求，禁止为表现分组新增模块框、分隔线、区域标题或装饰性图形。图纸外框与原有非电路保留区域不属于新增模块装饰。

## 局部修改与整页优化

用户已确认采用两种验收范围，记录为当前execution_rules.edit_scope.acceptance并参加规则指纹：

- local：针对明确对象及必要关联的局部修改。全图器件身份、逐脚网络和范围外不变量仍核对；受影响对象/文字/导线必须通过对应检查，全图不得新增或加重已观测问题。与修改无关且实际确认未变的既有排版问题/未知单列待办，不扩大为全页修图，不声称全页通过。
- page：新建/整体优化完成时执行全页图面验收，实际问题或没有有效检查证据仍阻断保存；文字不强制精确量测。明确局部任务采用local。只读检查不触发保存。

局部模式不豁免电气/范围未知或实际图面未检查；文字测量缺项可由本次有效图面审阅覆盖，不扩展成逐项后台属性审计。原报告与最新回读不一致须重查。保存一次、关闭/打开和持久化验证共用原门禁。不同任务按实际授权选择范围，不要求用户手写数据或为同一已确认原则反复签字。

## SCH-L01 功能关系识别（用户 G01）

移动前读取并确认器件、引脚、网络、电源关系、控制关系、信号连接、重复结构及已有层级。依据共同完成的局部功能与紧密连接建立临时分组。

不能仅因连接同一公共电源、地或其他全局网络就判为同组。分组只服务布局，不改变原设计结构或网表；不能自动编辑已有层级或拆分符号。

## SCH-L02 整体关系与阅读顺序（用户 G02）

先分析组间实际关系，再确定相对位置，使主要信号流、电源流、控制流、数据流及功能依赖可自然追踪。优先输入在前、输出在后，上游在前、下游在后；主路径连续、反馈靠近对应对象，强相关靠近，无关功能适当分离。

当前采用“兼顾后续PCB的原理图布局”：复用功能分区、核心与专属外围的邻近关系、关键路径的上下游关系；原理图具体坐标、间距和朝向仍服务符号引脚及可读性。封装焊盘顺序、板框、机械定位、回流、热与制造条件属于后续PCB约束，不由原理图位置推定已满足。未开发PCB时仅记录布局意图，不操作PCB，也不宣称布局传递接口已适配。

左→右、上→下仅是默认阅读偏好，不能破坏实际逻辑。不得将参考设计的固定位置、区域、网格或分页推广为通用规则；平台合法连接网格属于工具适配参数，不是固定版式。

## SCH-L03 组内器件摆放（用户 G03）

确定整体关系后再整理组内对象。优先靠近直接相连对象、同一局部功能对象、连续路径对象、同一支路/反馈/偏置/滤波/保护等局部网络对象，以及与特定引脚强相关的外围。主连接路径应容易追踪。

“相邻优先连接”只用于已由实际逐脚网络确认相连的对象；不能因距离近、属于同组或共用VCC/GND而新增连接。先确定连接关系，再安排邻近位置和短线，不能用最短距离代替电路理解。

不按器件类型、位号、封装或大小机械排列。重复或相似结构保持相似顺序、方向、间距和接线结构，实际连接要求不同的情况保留差异并说明依据。

## SCH-L04 器件方向（用户 G04）

结合功能流向、真实引脚位置、主要连接方向和周围支路关系选择朝向，优先一侧进入、另一侧离开，减少折返/绕线。输入或控制侧朝上游，输出侧朝下游，正电源趋上、地和负电源趋下，均为默认阅读偏好。

旋转、镜像或重新定位不得改变器件身份、Designator、Pin Number、Pin Name、极性或 Net。必须变换并核对真实引脚坐标和文字占位，不能从符号外观猜极性或交换脚号。

## SCH-L05 导线与网络连接（用户 G05）

局部连接优先清晰的实际导线：短、正交、沿设计工具合法网格，少拐点/折返/交叉，不绕无关对象。禁止穿越无关器件、器件文字或网名，制造含糊连接点，或为了持续拉线跨越大量无关电路。

直接相关且距离近的对象优先直连。较远、跨功能区域或直连明显降低可读性时，可用当前工具支持且当前任务允许的合法网络方式；长期默认仍为 SCH-G02 的“导线＋真实网络名称”、禁止六边形端口，网名位于对应导线上方。不自动把已要求的真实直连改成同名标签岛；相同网络不证明局部物理线树完整。

不设置适用于全部原理图的固定最大导线长度。评价某种表达是否比合法替代方式更容易理解电气关系，同时核对无节点交叉、连接点、线岛与显式未连接的原有语义。

## SCH-L06 网络名称与文字（用户 G06）

网名必须是实际电气连接对象，不能用普通文本模拟。它须明确关联对应网络，名称一致、方向一致、容易辨认、与导线关系清楚，不与器件、引脚、其他导线或文字重叠；与自身导线的合法关联按工具语义核验，不把合法连接误报为碰撞。

不得为排版修改网络含义、合并不同网络、拆分相同网络或擅自重命名。位号、参数、引脚文字及必要标注在布局阶段即算占用空间，提前预留；文字保持正常阅读方向，同类相对位置一致，不更改字段内容。

所有实际可见必要文字均须检查，隐藏元数据不占图面。默认以当前图面确认文字易读且不遮挡，按需测量；后台属性可见性或文字框未知不要求逐项清零。有绑定当前快照及验收范围的实际图面审阅，可以补足文字测量缺项；没有图面检查也没有充分测量时列为未检查，不填零面积或修改/隐藏属性制造通过。

## SCH-L07 页面空间与视觉层次（用户 G07）

使用实际有效图框，避开图签、页码、标题及明确保留区域和非电路对象。组内适度紧凑，相关对象靠近，无关对象适当分离，可以留白表达功能边界。

不为填满页面扩大间距，不为压缩面积造成文字/导线拥挤或关系混乱。对齐、等距、对称为低优先级优化，不影响功能和连接可读性才执行。纸张/分页变化需遵循当前任务范围，不能伪造边界或自动扩大授权。

## SCH-L08 检查、修正与验收（用户 G08）

| 层级 | 检查内容与判据 |
|---|---|
| P0 电气完整性 | 身份、位号、引脚、极性、网络关系及原有连接语义保持不变；前后逐脚比较连接或网表。任一差异均使排版无效；单纯网表同名不能代替必要的原有物理直连检查。 |
| P1 图面明确性 | 检查越界、对象/文字重叠、导线穿对象、含糊交叉/接点、未实际接入标签及明显错误方向，结果定位到对象ID。 |
| P2 功能可读性 | 能追踪来源→中间处理→去向；强相关靠近、主路径/支路/反馈清楚，重复结构一致，无关功能未被无意义长线混在一起。判断依据与覆盖明确，无法判定就列未检查。 |
| P3 几何优化 | 满足P0～P2后才优化对齐、间距、线长、拐点、交叉、留白、对称和页面利用率；无改进保留合法基线，不扩大无关改动。 |

每项记录通过、不通过或未检查及实际证据。检查器覆盖不足不能登记为通过；语义可读性不得伪装成纯几何分数已证明，ERC/DRC/API成功不能代替逐项结果。

## 最小必要修改

写入前记录问题对象ID、关联范围和拟改动。修正顺序默认是：**文字位置 → 局部导线 → 器件位置/方向 → 局部功能组位置 → 更大范围重新布局**。仅当较小范围不能解决时才扩大，保留不能解决的证据；扩大仍限授权范围，不自动变成全页重绘。

移动器件/组时同步处理必要关联线和标签，保证范围外对象的身份、属性、几何及逐脚网络不变。原生合并线树只能整体替换时，限最小图元并保留无关支路；超时/部分成功先回读，不重放成功批次。现有工具不支持安全移动时报告具体缺口，不拆坏连接绕过限制。

## 冲突优先级

在当前有效授权和任务规则内，排版优先级固定为：**电气正确性 ＞ 连接无歧义 ＞ 功能关系清楚 ＞ 阅读路径清楚 ＞ 局部连线简洁 ＞ 对齐与间距 ＞ 页面美观**。低优先级不得破坏高优先级；偏好不能覆盖硬性检查。

## 执行流程

读取当前设计 → 确认器件/引脚/网络 → 识别功能关系与内部功能分组 → 分析组间关系/阅读顺序 → 确定整体相对位置 → 整理组内对象/方向 → 预留文字空间 → 整理导线/网名 → 检查P0/P1 → 检查P2 → 优化P3 → 再检查受影响项并逐脚网表比较 → 本次授权范围完成并按local/page验收后一次显式保存 → 重开/回读验证。

已有图先分析并只整理问题区域，不把上述步骤理解成每次整页重排。执行前仍须有效的任务规则确认与范围校验；验证失败返回最小受影响阶段，不进入保存或最终通过。
