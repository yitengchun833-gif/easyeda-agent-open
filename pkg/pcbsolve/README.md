# pcbsolve

社区入口：[问题范围、可认领任务与离线验证](../../docs/pcb-solver-community-design.md)。

协调 `pcblayout` 与 `pcbrouting` 的 PCB 布局布线求解器，长期覆盖多层，当前实现二层。
它先生成完整布局候选，再在每个固定投影上
共同求解所有声明网络；实际拒绝线段中的焊盘、已有铜和竞争路径驱动相关完整组让位。布局、共同路由和单次寻路受
同一总状态预算约束，预算耗尽报告 `incomplete`，不声称全局无解。

当前支持固定装配面、原面平移/90°倍数旋转、TOP/BOTTOM、直线/45°路径，以及一个网络最多
两个实测尺寸的通孔。通过硬约束的结果依次比较移动组数、总位移、旋转次数、新增过孔、
实际线长和转折数，最多返回三个候选。差分、等长、自动铺铜、翻面和四层联合求解不在当前
能力内。

多层扩展继续使用本包协调层叠、允许换层、共同通道与布局反馈；模型、独立检查和搜索按
[A4 多层任务](../../docs/pcb-solver-community-design-detail.md#a4多层布局布线协调)分步推进。
当前二层拒绝边界保持，文档中的长期职责不表示多层求解已经可用。

组可声明 `translationSearch: {"step":10,"maxDistance":80}`（mil），不必提前给出成功坐标。
动态搜索以原始 anchor 为中心，遵守固定轴和最大距离；机械冲突可继续驱动邻组让位，状态去重
防止往返。每次移动都重新共同求解全部 demand，既有外部铜接触不得默默断开。
自动让位要求所有离开移动组的网络具有完整 demand 连接图；未覆盖的外部连接直接报错。
旧 `offsets` 请求仍按声明范围运行，不由少量需求推断整板可布。

共同试布先在固定布局中有界回溯路径与排网顺序，避免某条先走的短路线独占通道后立即
归因为布局需要让位。布局反馈邻域同时探索允许的整体转角，原地无法旋转的组可在移动后
重新尝试该朝向。各尝试共享总预算；这仍是有限启发式搜索，不保证枚举所有同层替代路线。

`Attempt.conflicts` 是实际拒绝线段与对象/网络/层的记录（每次尝试最多保留 256 个不同对象观察）；
它不是全局阻挡证明。状态预算或网格资源上限耗尽时不据此生成让位。`partialRoutes` 是失败尝试
中找到的部分路径，不代表所有网络共同通过。`Candidate.reservations` 保存同一完整路由及
线宽/净距/过孔，独立检查会重建对账；它不增加 `Board` 铜。`searchComplete` 仅表示当前有界
候选工作队列处理完毕，动态启发式没有枚举全部连续布局，也不保证最优。

`Check` 从原始板、独立请求和候选声明的 move 重建投影，再调用独立共同路径检查；它不调用
`Solve`，不相信候选状态或指标。候选由板语义哈希和请求哈希绑定，旧快照或篡改路径会失败。

`testdata/` 保存文件式典型案例，每例包含来源、开始状态、参数、独立期望和验证状态。

```bash
go test ./pkg/pcbsolve
# 保存可复核 SVG/JSON（仅离线测试输入，无 EDA 写入）
EASYEDA_PCB_SOLVE_ARTIFACT_DIR=/tmp/pcbsolve-review go test ./internal/app -run TestPCBAutomaticChannelArtifacts -v -count=1
```
