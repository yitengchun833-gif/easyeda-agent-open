## 原计划需要修正的地方

1. **工程创建提前，设计规则提前。** 工程先于原理图写入；PCB 导入后先设置两层及真实规则，
   再精细布局。8mil 线、6mil 导线间距和过孔占地会影响通道，不能等布局结束才发现放不下。
2. **布局期间就试算关键路径。** 固定 U6/CARD1 后，USB/UART、CAN、SWD、晶振的焊盘次序决定
   自由器件的朝向。先摆满 69 件、最后才尝试布线，会把原本可调整的问题变成绕行。
3. **电源与回流从布局开始考虑。** 不能把“关键网络先布”理解为把电源、去耦、EP 和 GND 空间
   留到最后。先预留主干和回流，局部去耦短线可随模块完成，长路径再按拥挤程度安排。
4. **样例必须能重现，而不只是列命令。** 现有 36 项是技术点目录；带 `<X>`、`<ID>` 的片段只是
   接口形态。成为可照做样例还需要说明参数如何从真实 pad/bbox 得到，保存计算脚本和实际回读。
5. **核查也会出错。** 旧布局报告把 C1/C2 的所有权反置；旧 CAN 计划只验证跨接和近端 ESD，
   未证明两条主路径先经过 R12 对应焊盘。保留反例并修正验证方法，不能照单接受报告结论。

## 推荐执行顺序

这是基于依赖关系的教学顺序；步骤内允许修改自由参数，事实检查随步骤进行，保存也贯穿全程。

| 步骤 | 做什么与为什么 | 留下什么事实/样例 | 来源 |
|---|---|---|---|
| 0. 读题拆点 | 合并正文、评分表、原理图和 BOM；区分固定、单轴自由、完全自由及禁区 | 69 件、15 区、逐引脚连接/NC、单位与来源；未确认字段单列 | p1–8、图 p1、BOM |
| 1. 建工程并复现原理图 | 建立隔离 Demo；按题图位置关系、连接表达、标签、功能注释复现；保留 LED 电压显示和图签 | 身份、pin→net/NC、显示属性、图面表达和默认 DRC 分别回读 | p1–2、p7 |
| 2. 转 PCB 并设置规则 | 确认正确 Board 绑定、69 个实例与焊盘网络；设置两层、间距、线宽、过孔和 PWR 类 | 实际规则名、值、成员及父子绑定；配置成功不代表已有铜自动合规 | p2、p5、p7 |
| 3. 建机械基准 | 90×50mm、R3、0.254mm 线宽、左下显示原点；固定四孔、U6、CARD1 | 中心线尺寸、原点与几何坐标区分、坐标语义、角度、锁定 | p2–3 |
| 4. 明确占地与板边空间 | 先准备 LCD 封装元件禁放区；安排接口插拔、按键按压、屏幕与光敏采光空间 | 封装 region 类型/边界/保存及实例绑定；板边关系及完整外形 | p3–4 |
| 5. 由关键路径决定自由布局 | 看 U6 真实引脚出口，决定 U4、U5、X1、USB1、H1 与 CN1 自由 x；试算短通道 | 模块朝向、路径草案、绕行原因及调参前后差异 | p4–5 |
| 6. 放外围并组织局部回路 | 去耦逐脚归属，LDO 电容朝向输入/输出，蜂鸣器/背光成组；预留主干和顶层回流 | 电容→芯片脚表、焊盘距离、输入/输出电源路径与 GND 返回路径 | p4、p7–8 |
| 7. 局部出线与关键布线 | 安排 EP 散热孔和必要地扇孔；晶振优先短直，完成受限顶层网络；局部去耦与电源短线同步考虑 | 焊盘端部出口、缩颈、层、每网过孔、必经焊盘、实际轨迹 | p5–6、p8 |
| 8. 电源主干与普通信号 | 沿预留通道连接电源及其余信号；电源按电流选宽，普通信号按网核对 ≤2 个过孔 | 全部端点连通、实际宽度、过孔尺寸与数目、无断头 | p5–6 |
| 9. GND 与丝印 | 双面 GND、必要缝合和连通回流；接口逐脚注释、Arial ≥45mil、TOP、最多两种方向 | 铜对象和实际连通、焊盘避让、字体方向及身份文字 | p3–4、p6、p8 |
| 10. 泪滴与最终保存 | 真实泪滴能力可用后创建，再重建铺铜；复核 100% 布通、PCB DRC 无错误和保存重开 | tracks/vias/pours/teardrops、DRC、typed save/reload/readback；缺口如实保留 | p6、p8 |

第 7 步内部可因真实拥挤调整 USB/CAN/UART/SWD 的先后；依据是是否影响必须保留的通道，
不是把某一份顺序表当固定算法。初期就应检查连接和 DRC，末尾是完整复核。

## 机械与使用空间：先把不能移动的东西放清楚

固定坐标全部用 mm 保存题目原值，送入命令时再换算：`mil = mm / 0.0254`。

| 对象 | x / y（mm） | 角度 | 固定性 |
|---|---|---|---|
| SCREW1 / SCREW2 | (3,47) / (87,47) | 0° | 锁定 |
| SCREW3 / SCREW4 | (3,3) / (87,3) | 0° | 锁定 |
| U6 | (45,25) | 0° | 锁定 |
| CARD1 | (79.5,25) | 90° | 锁定 |
| CN1 | (自由 x,42) | 180° | 题目不要求锁定；x 留给 CAN 通道优化 |

本次样例按 footprint anchor 执行。原题没有写 anchor/bbox-center 的定义，迁移时要保存语义
依据，不能把渲染 bbox 中心当成器件坐标。

USB1、H1、LED1、按键和光敏都要在板边，其中 USB1 朝板外；LED1 还要靠 USB1，光敏还要远离
LED1。因此“靠 USB”不能代替“在板边”，“按键等距”不能代替“板边方便按压”。
先给板边功能分配空间，再把专属外围排在内侧；不要先把中间填满，再把接口塞到空隙里。

LCD 禁的是封装外形内的**其他元件**，不是自动禁掉所有铜与走线。当前无人重叠不等于封装中
已经存在题目要求的 region。U3 已正确绑定 `C2890616`、`OLED-SMD_ST7735S` 和既有 3D model，
加禁放区必须保持这三项关联，不能换模型。个人库副本中的 no-components region 只是 typed
接口试验，没有绑定当前 U3；系统封装无损复制到当前工程库的带分类/不带分类两次调用又均由
宿主拒绝，普通板级 region 也会让 owner U3 自身产生 DRC。该组合能力现标 `unsupported`，
本 Demo 跳过 region 写入，只用 U3 实测外形作为参数化 Layout 避让代理，并明确保留考点未满足。
不得写系统库、重绑个人副本、忽略自违规 DRC 或用 GUI 补齐。

## 电源与去耦：看引脚和回流，不只看靠近芯片

从原题图建立下面的归属。C1/C2 等即使同值同网，也不能根据布局最近距离重新分配身份。

| 电容 | 对应对象/引脚 | 主要观察 |
|---|---|---|
| C1 / C2 | U1.5 VCC / LED1.1 VDD | 两个 +5V 用电对象各有去耦；旧报告的交换建议作废 |
| C3、C4 | U2.3 VIN | 输入 10µF、100nF；源到电容再到 VIN |
| C5、C6 | U2.2/.4 VOUT/TAB | 输出 10µF、100nF；两个输出焊盘同属 +3V3；GND 返回 U2.1 |
| C9 / C10 | U4.8 V3 / U4.5 VCC | 逐脚去耦，不能只验证都在 +3V3 |
| C12、C13 | U5.3 VCC | 10µF、100nF，较小电容靠电源脚并保留短回流 |
| C14 / C15 / C16 | U6.1 VDD / U6.5 VDDA / U6.17 VDD | 一一对应，U6 旋转/移动时按真实脚重算 |
| C18、C19 | CARD1.4 VDD | 10µF、100nF；卡座固定后排电容，不能牺牲其固定位置 |
| C7 | U3.10 VDD | 与 LCD 禁放边界一起求解；单凭超过自定距离不能声称原题矛盾 |

“先经过电容”是供电铜线先到电容的电源侧连接点，再到芯片；电容仍是电源到 GND 的并联
器件，不能串进供电线上。“先大后小”也不是把所有大电容推远：两只都应靠对应输入/输出端，
兼顾短回路。LDO 输入可教学为 `5V 源 → C3 电源焊盘 → C4 电源焊盘 → VIN`；输出样例可
采用 `VOUT/TAB → C5 电源焊盘 → C6 电源焊盘 → 负载支路`，但后者是本例的空间/走向方案，
原题没有把输出端顺序画成唯一 PCB 答案，还须符合实际器件手册和短回路要求。

检查时分别追踪正电源路径、两只电容的地端以及芯片 GND。本题要求 LDO 输入输出电容地可在
顶层回到芯片地，仅用底层一大块 GND 得到“同网”不足以证明。移动整个 LDO 模块后要重新计算
进出模块的路径；只平移器件、保留旧走线不算可迁移样例。

## 关键网络：必须看实际走向

| 网络 | 题目要求 | 布局阶段先解决的事 |
|---|---|---|
| OSC_IN / OSC_OUT | 靠 MCU、不在板边；短直、避免底层、顶层包地净空 | U6.2/.3 与 X1.1/.3 的相对次序；C21 对 OSC_IN、C20 对 OSC_OUT；X1.2/.4 为 GND |
| USB_D+ / USB_D- | TOP、不得过孔换层、类差分，不强制等长 | USB 重复数据脚与 U4.1/.2 的通道；不要为了等长蛇形绕远 |
| CANH / CANL | TOP、不得过孔换层、类差分，不强制等长；先经过 R12 再到端子，D1 靠端子 | U5、R12、CN1 信号焊盘的贯通关系；D1 的保护支路及回地短 |
| PA9 / PA10 | TOP、不得过孔换层 | U4.7 RXD→PA9，U4.6 TXD→PA10；同时考虑 U4 的 USB 侧 |
| PA11 / PA12 | TOP、不得过孔换层 | U5.4 R→PA11，U5.1 D→PA12；同时考虑 U5 的 CAN 总线侧 |
| PA13 / PA14 | TOP、不得过孔换层 | H1 的实际针脚与 U6.23/.24；功能丝印不能按视觉排列猜针号 |

晶振 TOP/0via 是推荐样例方案；原文并未像 USB/CAN/PA9–PA14 那样单列绝对零过孔禁令。
晶振包地也不是任意画一个 200mil 禁区；要查实际 GND 连接、振荡线附近铜和寄生影响。

CAN 的两条主路径应表达为：

```text
U5.7 CANH → R12 的 CANH 焊盘 → CN1.2 CANH
U5.6 CANL → R12 的 CANL 焊盘 → CN1.1 CANL
R12 = 120Ω，跨接以上两个焊盘；D1 靠 CN1，分别接 H/L 并短路径回地。
CN1.3 = GND。
```

“先经过 120Ω”不是在 CANH 或 CANL 中串联 120Ω，而是两根走线分别触达跨接电阻的对应
焊盘后继续到端子。旧的 `U5 → D1 → CN1 + R12 支路` 计划只证明网表连接，未证明本题要求
的布局走向；它只能保留为反例。

SWD 的实际顺序是 H1.1=GND、H1.2=PA14/CLK、H1.3=PA13/DIO、H1.4=+3V3。题目列出
“3V3，DIO，CLK，GND”是功能要求，不是让所有朝向都按从左到右抄这四个词。

焊盘末端出线还需要实际铜段证明：不能在电阻、电容、电感焊盘中间横穿；窄焊盘局部缩颈，
线宽不大于焊盘宽度且本题信号不小于 8mil。普通转折避免直角/锐角。只有 U6 EP 可以使用
焊盘内散热孔，其他焊盘不使用 via-in-pad。

记录首次必要阅读量、工具命令数、返工原因、墙钟时间与 daemon 耗时。目标是让例子更清楚、
工具更可靠；不要为每个错误再加一个阶段许可，或用更严格的任意距离把合理方案挡掉。

## 你自己练习时的自查方法

每做一步，尝试回答三个具体问题：它满足题目的哪一句；为什么此时安排；实际哪里能证明。
例如摆完 LDO 时，能指出 VIN/VOUT/TAB/GND、每只电容服务的引脚和供电/回流路线；摆完 CAN
时，能沿 H/L 各从 U5 经过 R12 对应焊盘走到端子，并指出 ESD 靠端子的理由。

固定尺寸题练习“约束优先、保留通道”，可调尺寸自建板练习“模块和接口先组织、据空间定板框”。
后者保持独立教学变体，不改动本题 90×50mm 基准。两者都要在精细布局前确认制造规则。
