# v1.6.0 测试用例（进行中）

执行 Agent 只收到[原始需求](../../../../esp32MiniRequire.md#一客户原始需求)和公开 Skill；
本表是逐场景验收判据，不作为客户答案喂入。无历史上下文执行 prompt 与操作顺序见
[Codex Web EDA 执行步骤](../../../codex-web-eda-runbook.md#3-让无历史上下文的-codex-执行与独立验收)；
[原理图专项记录](../../../reviews/2026-09-23-v1.6.0-schematic-acceptance.md)只保存运行结果。

| ID | 输入与步骤 | 通过判据 |
|---|---|---|
| V1 | 安装候选后由用户重开 Web 页，连续核对 CLI/daemon/运行中连接器与目标页；页切换和首个完整读取后再次核对。 | 运行版本精确同版，窗口身份稳定；旧连接器重连或版本回退必须停写，安装列表和单次 health 不计通过。 |
| V2 | `project.create` 返回空 UUID 或打开失败时，读取目标团队完整工程清单并按唯一名称核对，再决定继续、报 partial 或拒绝重试。 | 不能仅凭错误回包断定未创建；清单不完整、重复名称或身份不明时停写，不盲目再建。 |
| M1 | 在真实页或专用测量页对全部器件测官方位号 bbox，按来源绑定回源；若建临时页，按创建 UUID typed 删除。 | 每件唯一可见位号、parent 和页身份可回读；缺失、重复、漂移拒绝。临时页删除后页清单与目标页完整对象恢复，经 save→reload→fresh readback 才算清理持久化。 |
| M2 | 从 typed 官方数据采集各页红色绘图区内框与图签真实占位，再对整页候选做入框检查。 | 组件、位号、导线、标记和模块框均有精确边界证据；只有外纸张尺寸/估计工作矩形时记 `unsupported`，不能算入框通过。 |
| F1 | 从唯一原始需求独立选型，生成连接/NC、核心外围归属、区内与整页布局、固定 compose 和受保护队列。 | 需求逐条覆盖；所有物理脚、direct 真实线树和空间约束完整；每个候选报告的 `sourceSha256` 与不可覆盖的配对输入原始字节哈希一致，重复计算哈希一致。 |
| F1-Z | 区内有界搜索失败后，在原源副本中尝试把拥挤功能区拆为两个非空 zone，运行 `sch zone-review` 再决定是否重求解。 | 每件唯一归属；所有跨区网策略合法，原 `direct` 真实线树及核心/专属外围 attachment 不被端口或拆区弱化。违反任一条件时写前拒绝，该负例通过不表示 F1 完成。 |
| F2 | 逐页 dry-run、Apply、strict gate、DRC、保存、真实重载、新鲜回读。 | 完整对象与源对账；0 overlap/0 fatal；所有页面和图签持久化。 |
| E1 | 逐段核对 USB 供电与数据→CH340→UART、DTR/RTS→EN/BOOT，以及 BOOT/RESET 手动按键路径；列出 DTR/RTS 四种输入态。 | 每态 EN/BOOT 静态结果均由实际器件和导线证明；双低不持续复位，严格“插 USB 可免手动下载”解释下有控制路径。静态图不能证明实板烧录或串口行为。 |
| L1 | 从保留源选择合法新位置整体移动一个核心和专属外围，重算本区并现场应用。 | 区内附着物随动；范围外身份、属性、网络、NC、几何不变；保存重载后差分成立。 |
| L2 | 仅当新鲜回读存在真实旧线、旧标记和单脚错误时，按源修复该支路。 | 目标错误消失，旧 findings 不增加；无真实前提记 `not-run`，不人为造现场错误。 |
| N1 | 用过期状态、同件数异导线/标记、跨页漂移、缺归属、非网格数据，以及从保留源构造的受阻局部移动作负例。 | 首次设计写入前非零拒绝；现场前后完整对象与语义哈希不变，不能只核对零删除；缺 getter 不降级为通过。 |
| N2 | 对宿主属性 `KeyVisible` 批量读取、按 ID 复读和状态重置分别注入 `undefined`；再测真实页完整快照与官方当前工程源。另覆盖 SDK 可读、原生源不含的自动生成属性。 | 仅当当前工程与目标 `SCH_PAGE` 身份稳定、原生同 ID/key/parent/value 且字段明确为 `boolean/null` 时恢复不可读字段；源缺项/漂移/冲突时报对象级错误并零删除。SDK 原本完整可读的生成属性仍留在快照中，不要求原生源重复出现。 |
| R1 | 同源/参数/版本重复离线计算，故意中断一个局部写批次后 fresh 回读。 | 几何与哈希可重现；中断后按实际状态重算，不盲重放。 |
| E2E | 独立执行固定客户需求的 S0–S6 + P0–P10 全流程，原理图通过后转 4 层 PCB、布局、布线、铺铜、DRC、保存重载。 | 客户原始需求逐条成立；4 层电源树、GND 内电层、丝印极性、天线 keepout、孔位、网络连通及最终持久化通过。 |

每例记录实际命令、输入哈希、目标项目/文档、原始响应、首个失败对象和独立复核结果；
`blocked`、`not-run`、`offline-only` 均不计通过。
